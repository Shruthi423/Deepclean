# Deep Clean Context for VS Code

This lightweight extension adds Command Palette actions for Deep Clean.

Commands:
- Deep Clean: Analyze Current Project Claude Session
- Deep Clean: Clean Current Project Claude Session
- Deep Clean: Analyze Current Project Codex Session
- Deep Clean: Clean Current Project Codex Session

The extension runs the installed `deepclean` CLI in VS Code's integrated
terminal. Cleanup remains interactive and user-controlled.
